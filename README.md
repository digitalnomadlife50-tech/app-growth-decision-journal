# Thread

Thread is a proposed internal codename for this independent decision journal, not an approved Wikimedia project. It documents a Reading continuity proposal for the Wikipedia apps. Continue reading is the proposed user-facing feature name.

A responsive static site styled after Wikipedia's Vector 2022 reading layout and informed by Wikimedia Codex typography guidance. It is an independent interview work sample, not an official Wikimedia Foundation page and does not use Wikimedia logos or imply endorsement.

## Deploy to Vercel
1. Create a Git repository and add the contents of this folder.
2. Import the repository into Vercel.
3. Select **Other** as the framework preset.
4. Leave the build command empty and set the output directory to `.`.
5. Deploy. No environment variables or build step are required.

## Design references
- Vector 2022 design documentation: https://www.mediawiki.org/wiki/Skin:Vector/2022/Design_documentation
- Wikimedia Codex typography: https://doc.wikimedia.org/codex/main/style-guide/typography.html

The layout uses a restrained article-first hierarchy, system sans-serif body text, serif article title and section headings, blue links, thin rules, a contents sidebar, and compact tables. It is not an exact copy of Wikipedia's proprietary or live interface assets.
